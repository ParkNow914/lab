Ver o estrago antes de causá-lo

Escreva HCL à esquerda. Ele é analisado de verdade: o grafo de dependência sai das referências que você escreveu, e o plano compara a configuração com o estado atual. Aplique, depois mude alguma coisa e planeje de novo — é o ciclo inteiro do Terraform, sem nuvem nenhuma envolvida.

HCL parser escrito do zero grafo de dependência plan / apply 0 dependências
Por que este projeto É assim que eu provisiono infraestrutura de cliente. O plan antes do apply é a rede de segurança que evita derrubar produção — e a parte que mais gente ignora é que a dependência não é declarada: ela é deduzida de quem referencia quem. Escrever ${aws_vpc.principal.id} já é dizer “isto vem depois daquilo”.

    O grafo de dependência deduzido das referências

    Cada coluna é uma camada: tudo dentro dela pode ser criado ao mesmo tempo, porque nada ali depende de nada ali. É assim que o Terraform paraleliza — e é por isso que dependência circular é erro fatal, não aviso: não existe ordem possível.
