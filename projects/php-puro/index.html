Como o Blade realmente funciona

Um motor de template não interpreta o template a cada requisição — ele compila o template para PHP puro, e daí em diante quem roda é o próprio PHP. Edite o template ao lado e veja, no painel do meio, o código PHP que ele vira antes de qualquer coisa executar.

PHP 8.4 php-wasm tipos, enum, match 0 dependências roda no navegador
Por que este projeto PHP carrega fama de bagunça por causa de código dos anos 2000, não da linguagem atual. Um motor de template limpo em PHP 8 — com tipos declarados, propriedade promovida, enum e throw como expressão — desfaz isso. E mostra o mecanismo por trás do framework mais contratado do mercado brasileiro.

O motor

{{ $nome }} vira <?= e($nome) ?> em tempo de compilação. Não há busca em texto na hora de renderizar — por isso template compilado é rápido. E é por isso que {{ }} existe em vez de <?= ?>: esquecer de escapar é o erro mais comum e mais caro em template, e aqui é impossível esquecer. A versão sem escape, {!! !!}, tem sintaxe feia de propósito.
