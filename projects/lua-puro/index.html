Script de terceiro rodando sem poder fazer estrago

O código Lua ao lado desenha a cena acima — e é o visitante quem o escreve. Ele roda de verdade, num Lua 5.4 completo, mas só enxerga o que este programa decidiu entregar. io, os.execute e require simplesmente não existem lá dentro. É por isso que Roblox, WoW e Neovim escolheram Lua.

Lua 5.4 Wasmoon (Lua em WASM) linguagem embarcada API controlada pelo hospedeiro roda no navegador
Por que este projeto Lua existe para ser embutida com segurança dentro de outro programa. O ponto não é a sintaxe: é que o hospedeiro decide exatamente quais funções o script enxerga, e o script não tem como escapar dessa lista. É esse contrato que permite rodar código de terceiro sem entregar a máquina junto.
