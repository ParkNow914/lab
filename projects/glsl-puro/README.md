# Cena 3D por ray marching em shader

**GLSL (puro)** · Roda no navegador

Mundo 3D inteiro descrito por função matemática e renderizado pela GPU — sem malha, sem vértice, com editor de shader ao vivo.

## Por que este projeto

Shader é programação paralela extrema: o mesmo código roda em milhões de pixels ao mesmo tempo. Ray marching com campo de distância é o ápice disso.

## Como roda

- **Execução:** Página estática, sem servidor
- **Toolchain:** `WebGL2 / WGSL`

## Build

Nenhum. A página é servida como está; a linguagem roda no navegador por um
runtime carregado via CDN.
