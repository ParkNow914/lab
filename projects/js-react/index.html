É o bug mais comum de React em produção: silencioso, invisível em teste de unidade, e só aparece quando a lista muda de ordem com o usuário no meio de um formulário. Aqui ele acontece em dois cliques, com o DOM instrumentado para provar o que o reconciliador fez.
