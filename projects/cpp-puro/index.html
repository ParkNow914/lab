Três mil corpos colidindo, a 60 quadros por segundo

Clique e segure para atrair tudo. A física — integração de Verlet e resolução de colisão — é C++ compilado para WebAssembly. O que faz isso caber em 16 milissegundos não é a linguagem sozinha: é a grade espacial que evita comparar cada corpo com todos os outros.

C++20 integração de Verlet grade espacial 13 KB de WebAssembly roda no navegador
Por que este projeto C++ vive onde performance encontra abstração: std::vector, lambdas e estruturas alinhadas, sem abrir mão de controlar cada byte. Uma simulação de milhares de corpos é o caso em que a escolha de estrutura de dados importa mais que a linguagem — e dá para ver esse custo mudando na tela.

Por que a grade importa

Sem estrutura espacial, detectar colisão exige testar todo par de corpos: com 3.000, são 4,5 milhões de testes por quadro. Com a grade, cada corpo só conversa com quem está nas células vizinhas.

Suba os subpassos e veja a pilha ficar mais firme — e o custo subir na mesma proporção. É a troca clássica de simulação: cada subpasso é uma rodada inteira de colisão a mais, comprando estabilidade com tempo de CPU.

A integração de Verlet não guarda velocidade em lugar nenhum: a velocidade é a diferença entre a posição atual e a do quadro anterior. Empurrar um corpo para fora de uma parede já corrige o movimento dele, de graça.
