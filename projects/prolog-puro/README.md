# Resolvedor de enigma lógico

**Prolog (puro)** · Roda no navegador

O enigma das cinco casas (Zebra): você declara as regras, não o algoritmo, e o motor encontra a única solução possível.

## Por que este projeto

Programação lógica inverte tudo: descreve-se o problema, não o passo a passo. É a demonstração mais clara de que existe paradigma além de imperativo e funcional.

## Como roda

- **Execução:** Transpilado para JavaScript — executa na máquina do visitante
- **Toolchain:** `Tau-Prolog`
