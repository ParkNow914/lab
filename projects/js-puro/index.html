Motor reativo em 200 linhas

Mexa no carrinho abaixo. Nenhum código de tela manda atualizar total, desconto ou frete — eles se recalculam sozinhos porque leram os dados que mudaram. É o mesmo mecanismo que existe dentro do Vue, do Solid e dos signals do Angular, aqui sem framework, sem build e sem uma única dependência.

JavaScript puro Proxy + Reflect ES modules nativos 0 dependências sem etapa de build
Por que este projeto Todo mundo usa React sem saber o que ele faz por baixo. Reimplementar o núcleo reativo obriga a entender rastreamento de dependência, limpeza de dependência morta e agrupamento de atualização — os três pontos onde framework de verdade ganha ou perde desempenho.
