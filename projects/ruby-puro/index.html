Uma linguagem que é Ruby disfarçado

As regras ao lado parecem uma linguagem própria. Não são. É Ruby, dobrado com instance_eval, method_missing e blocos até parecer outra coisa. Não existe parser aqui — e é exatamente por isso que has_many :pedidos e validates :email existem no Rails.

Ruby 3.4 ruby.wasm DSL interna metaprogramação 0 dependências
Por que este projeto Ruby é a melhor linguagem do mundo para criar DSL. Quase todo portfólio mostra um CRUD em Rails; quase nenhum mostra a mecânica que torna o Rails possível. Escrever a regra de negócio numa linguagem que o próprio negócio consegue ler é a diferença entre código que envelhece bem e código que só o autor entende.

Como o truque funciona

instance_eval executa um bloco trocando o self. É por isso que regra só existe dentro de Regras.definir, e quando/entao só existem dentro de regra — sem nenhuma variável global e sem poluir nada.

method_missing resolve cliente e total na hora da chamada, contra o pedido. Eles não estão declarados em lugar nenhum. E o par obrigatório respond_to_missing? está lá: sem ele, respond_to? mentiria — é o erro clássico de quem aprendeu metaprogramação pela metade.

Blocos guardam a condição sem executá-la. quando { total > 500 } não compara nada na hora da definição: guarda o código para rodar depois, com outro self.
