# Resolvedor de Sudoku com backtracking

**Python (puro)** · Roda no navegador

Gera e resolve tabuleiros com propagação de restrições, mostrando a árvore de decisão e cada retrocesso em tempo real.

## Por que este projeto

Python é a linguagem de pensar em voz alta. Backtracking com geradores e recursão fica quase idêntico ao pseudocódigo — e roda no navegador via Pyodide.

## Como roda

- **Execução:** Compilado para WebAssembly — executa na máquina do visitante
- **Toolchain:** `Pyodide`
