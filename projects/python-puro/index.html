Backtracking que você vê acontecer

O algoritmo tenta um número, segue em frente e, quando chega num beco sem saída, volta e desfaz. Todo mundo aprende isso na teoria; aqui cada tentativa aparece em verde e cada retrocesso em vermelho. O Python que resolve está à direita, rodando de verdade no seu navegador.

Python 3 puro Pyodide (CPython em WASM) sem bibliotecas recursão + backtracking roda no navegador
Por que este projeto Python é a linguagem de pensar em voz alta: o resolvedor abaixo é quase idêntico ao pseudocódigo que se escreveria num papel. É isso que a torna a linguagem em que algoritmo se ensina — e, com Pyodide, o mesmo CPython roda aqui sem servidor nenhum.
