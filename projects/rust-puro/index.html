Uma linguagem de programação inteira, em 700 linhas de Rust

Lexer, parser de descida recursiva e interpretador de árvore — sem nenhuma dependência, nem wasm-bindgen. A linguagem tem variáveis, condicionais, laços, funções e recursão. Escreva no editor e execute: quem está rodando o seu código é Rust compilado para WebAssembly.

Rust 2021 0 dependências wasm32-unknown-unknown 121 KB de WebAssembly 4 testes unitários
Por que este projeto Rust brilha em software que não pode errar. Cada erro possível é uma variante de enum, cada operação que pode falhar devolve Result, e o match exaustivo faz o compilador recusar o código se eu esquecer um caso. Um interpretador escrito assim não tem como entrar em estado inválido — e é por isso que ele consegue reportar o erro com linha em vez de travar.

A linguagem

seja x = 10
x = x + 1
mostre "texto" + x
se x > 5 { … } senao { … }
enquanto x < 100 { … }
funcao nome(a, b) { devolva a + b }
embutidas: raiz, piso, abs, tamanho
operadores: + - * / % == != < <= > >= e ou nao

Sem wasm-bindgen. A ponte com o JavaScript é manual: a página aloca um buffer pelo alocar() do Rust, escreve o UTF-8 nele e recebe de volta um ponteiro para [tamanho][bytes]. WebAssembly só sabe trocar números — strings são uma convenção construída em cima disso.
