Um fractal inteiro em 593 bytes

Este Mandelbrot não foi compilado de C, de Rust nem de nada. Ele é WebAssembly, escrito à mão em formato texto — pilha de operandos, saltos rotulados e variáveis numeradas. É a forma final em que todas as outras linguagens deste laboratório acabam. Clique para mergulhar.

O preço de cada abstração

Todas estas demos do laboratório fazem cálculo pesado e todas viram WebAssembly. A diferença de tamanho não é o algoritmo — é o que cada linguagem precisa levar junto para funcionar.

linguagemtamanhoo que vai junto
WAT (escrito à mão)593 Bnada
C++13 KBstd::vector e matemática
C17 KBmalloc e matemática
Rust121 KBformatação, String, HashMap
Go2,4 MBescalonador e coletor de lixo

Nenhum desses números é “ruim”. O Go carrega 2,4 MB porque entrega goroutines de graça; o WAT tem 593 bytes porque não entrega nada — cada if e cada laço são rótulos e saltos escritos à mão.

O código é isto que o navegador executa

WebAssembly é uma máquina de pilha: local.get empurra um valor, f64.mul tira dois e devolve um. Não há expressão a*b+c — há uma ordem de empurrar e tirar. O laço é um block com um br_if que sai dele.
